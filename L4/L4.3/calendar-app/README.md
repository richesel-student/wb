# Calendar API Application

Высоконагруженный HTTP-сервис на Go для управления календарными событиями. Спроектирован по принципам **Clean Architecture** и оптимизирован для работы в конкурентной среде: использует асинхронное фоновое логирование, независимое планирование напоминаний и автоматическую архивацию устаревших задач.

---

## 🚀 Быстрый старт (Управление одной командой)

Для автоматизации локальной разработки и проверок используется ультимативный скрипт `./dev.sh`. Все команды запускаются из корня проекта.

* **Полный цикл проверки и тестов (Рекомендуется перед коммитом):**
  ```bash
  ./dev.sh dev
  ```
  *Скрипт автоматически освободит порт, запустит линтеры, прогонит юнит-тесты, поднимет сервер в фоне, протестирует API curl-запросами и корректно завершит процесс. Идеальный локальный CI/CD.*

* **Просто запустить сервер:**
  ```bash
  ./dev.sh run
  ```

* **Запустить только проверки кода (vet + линтер + юнит-тесты):**
  ```bash
  ./dev.sh check
  ```

* **Запустить интеграционные тесты API (на работающем сервере):**
  ```bash
  ./dev.sh test
  ```

## 🏗️ Архитектура и структура файлов

Проект разделен на изолированные слои, что обеспечивает слабую связность компонентов и простоту тестирования:

```text
.
├── dev.sh                       # Главный оркестратор и пульт управления проектом
├── Makefile                     # Базовые атомарные команды сборки и проверок
├── cmd/main.go                  # Точка входа, DI-контейнер и Graceful Shutdown
├── internal/                    # Изолированная бизнес-логика приложения
│   ├── calendar/                # Ядро: логика фильтрации событий (день/неделя/месяц)
│   ├── handlers/                # HTTP-контроллеры: валидация и обработка JSON
│   ├── logger/                  # Асинхронный неблокирующий логгер на Go-каналах
│   ├── middleware/              # Перехватчик паник (Recovery) для защиты сервера
│   ├── models/                  # Чистые доменные структуры данных (Event)
│   ├── repository/              # Потокобезопасное InMemory хранилище (Актив/Архив)
│   └── worker/                  # Фоновые воркеры напоминаний и архивации данных
└── scripts/                     # Набор интеграционных bash-скриптов для проверки API
```

## 📡 Спецификация API и примеры запросов

### 1. Проверка состояния сервиса (Healthcheck)
```bash
curl -X GET http://localhost:8080/health
```
*Ответ (200 OK):* `{"status":"ok"}`

### 2. Создание календарного события (POST /events)
```bash
curl -X POST http://localhost:8080/events \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Сдача проекта",
    "description": "Проверка Clean Architecture и покрытия тестами",
    "start_time": "2026-05-16T22:00:00Z",
    "end_time": "2026-05-16T23:00:00Z",
    "reminder_before_minutes": 15
  }'
```

### 3. Получение списка всех активных событий (GET /events)
```bash
curl -X GET http://localhost:8080/events
```

### 4. Обновление события по ID (PUT /events/{id})
```bash
curl -X PUT http://localhost:8080/events/1715873945000000000 \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Новое название встречи",
    "description": "Обновленное описание"
  }'
```

### 5. Удаление события по ID (DELETE /events/{id})
```bash
curl -X DELETE http://localhost:8080/events/1715873945000000000

```
