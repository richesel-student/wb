# Warehouse App

## 🚀 Запуск

```bash
chmod +x run.sh
./run.sh
```

## 🌐 Открыть

```
http://localhost:8080
```

---

## 👤 Логин

* admin / admin
* manager / manager
* viewer / viewer

---

## 🧪 Проверка

### 1. UI

* открыть http://localhost:8080
* нажать Login
* должна появиться таблица

---

### 2. CRUD

* Add → создаёт товар
* Edit → изменяет
* Delete → удаляет (только admin)

---

### 3. Роли

* viewer → только просмотр
* manager → без delete
* admin → всё доступно

---

### 4. История

* нажать History у товара
* отображаются изменения

---
